┌─────────────────────────────────────────────────────────────────┐
│ 🔧 BACKEND DEPLOYMENT (Deploy First!)                          │
└─────────────────────────────────────────────────────────────────┘

  1. Vercel Dashboard → Add New → Project
  2. Select GitHub repo
  3. Settings:
     ├─ Root Directory: server
     ├─ Framework: Other
     ├─ Build Command: (empty)
     ├─ Output Directory: (empty)
     └─ Install Command: npm install

  4. Environment Variables:
     ├─ PORT=5000
     ├─ NODE_ENV=production
     ├─ MONGODB_URI=mongodb+srv://...
     ├─ JWT_SECRET=your_secret_32+_chars
     ├─ GEMINI_API_KEY=your_key
     ├─ FAL_KEY=your_key
     └─ REPLICATE_API_TOKEN=your_token

  5. Deploy → Copy URL
     Example: https://ecolearning-backend.vercel.app

┌─────────────────────────────────────────────────────────────────┐
│ 🎨 FRONTEND DEPLOYMENT (Deploy Second!)                        │
└─────────────────────────────────────────────────────────────────┘

  1. Vercel Dashboard → Add New → Project
  2. Select SAME GitHub repo
  3. Settings:
     ├─ Root Directory: client
     ├─ Framework: Vite
     ├─ Build Command: npm run build
     ├─ Output Directory: dist
     └─ Install Command: npm install

  4. Environment Variables:
     └─ VITE_API_URL=https://your-backend.vercel.app/api
        (Use backend URL from step above + /api)

  5. Deploy → Done!
     Example: https://ecolearning.vercel.app

┌─────────────────────────────────────────────────────────────────┐
│ 🐛 QUICK TROUBLESHOOTING                                        │
└─────────────────────────────────────────────────────────────────┘

  Problem: Cannot connect to database
  Solution: Check MongoDB allows 0.0.0.0/0 in Network Access

  Problem: API calls return 404
  Solution: VITE_API_URL must end with /api

  Problem: CORS errors
  Solution: Already configured, try redeploying backend

  Problem: Environment variables not working
  Solution: Redeploy after adding variables

  Problem: Build failed
  Solution: Check Vercel build logs, test locally first
